## 🌟 Core Capabilities:
- 👑 **Master 1-Shot Outcome Engine (`autonomous_growth_architect`):** Ingests the product and stage to synthesize a complete growth system in one call: north star metric with input-metric tree, growth model decision matrix (PLG loops vs content/SEO loops vs paid vs sales-led), AARRR funnel map with healthy benchmarks per stage, analytics stack selection (PostHog vs Amplitude vs warehouse-native), and a 90-day experimentation roadmap.
- 📊 **Event Tracking Designer (`design_event_tracking`):** The tracking plan that makes every future analysis possible: object_action taxonomies, product-shaped core event tables (SaaS, mobile, marketplace, API), anonymous-to-identified identity resolution with B2B group analytics, client vs server-side rules (revenue truth is server-side), typed implementation wrappers, data quality guards, and GDPR-grade privacy compliance.
- 🧪 **A/B Test Engine (`run_ab_test_engine`):** Statistics that survive scrutiny: hypothesis framing, real sample-size math shown step by step (two-proportion z-test with power), full-week duration rules, guardrail metrics, the traps that invalidate most startup tests (peeking, SRM, multiple comparisons, winner's curse), honest analysis code with confidence intervals, and pre-committed ship/iterate/kill decision grids.
- 🔁 **Funnel Optimizer (`optimize_conversion_funnel`):** Two-layer diagnosis (quant finds where, replays find why), aha-moment discovery via retention correlation, and ICE-scored fix lists with expected lift ranges for every leak: visitors-don't-signup, signups-don't-activate, activated-don't-pay, and trials-don't-convert.
- 📈 **Retention Engine (`build_retention_engine`):** Cohort curve reading (decline-to-zero vs flatten vs smile — and what each demands), benchmarks by product category, ethical habit loop architecture (trigger-action-reward-investment), behavior-triggered lifecycle messaging sequences, churn prediction signals that fire weeks early, and resurrection playbooks with realistic recovery math.
